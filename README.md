# FluxKeyboardCompanion

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) that implements the [Flux Keyboard](https://fluxkeyboard.com/)'s contextual shortcuts.

Still WIP, since the API is very early, but it kinda sorta works. So far I've mapped all the tools, grabbed object controls, freecam controls, and text input focus.

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
2. Place [FluxKeyboardCompanion.dll](https://github.com/noblereign/ResoniteFluxKeyboardCompanion/releases/latest/download/FluxKeyboardCompanion.dll) into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
3. Start the game. If you want to verify that the mod is working you can check your Resonite logs.
